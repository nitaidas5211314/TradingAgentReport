#### 4. 传导机制：为什么这次 BTC-USD 特别脆弱

1. **实际利率渠道（主导）**：5y 名义约 4.95%–5.00%（由 2y 4.86% 与 10y 5.10% 插值）减去 5y breakeven 2.30% → **5y 实际利率约 2.65%–2.70%**，为多年高位。BTC 的“久期”极长（无现金流、价值完全来自未来预期），对贴现率变化最敏感；实际利率 +50bp 对应的估值压缩幅度在 15%–25% 量级，与本周实际跌幅方向吻合。
2. **美元渠道**：美元指数 121.88 高位 + 全球美元融资成本抬升 → 离岸杠杆（永续合约、以美元计价的套息）被动去化。
3. **机会成本渠道**：无风险 5.1% 的 10y 收益率意味着持有 BTC 的边际机会成本升至十余年最高之一，“零收益资产”的相对吸引力被系统性地削弱。
4. **政策不对称渠道（最关键）**：市场定价 **衰退 2% / 过热 71%**。**没有衰退 → 联储不需要降息 → 不存在 BTC 最擅长交易的“流动性转向”催化剂**。即便经济走弱，只要通胀在 3.8%，联储的看跌期权（Fed put）也不会被执行。**当前宏观为 BTC 提供的是一个“双向封死”的环境。**
5. **尚未触发的加速器**：HY 利差 3.20%（尚低）。**若升至 4.0%+，将从“估值杀”转为“信用/流动性杀”，BTC 目标位下移至 45k–50k。**
